While deploying first time follow below steps

1) Comment All 443 Services In nginx/default.conf

2) docker compose up nginx_1 -d --build

3) docker compose run --rm certbot certonly \
  --webroot -w /var/www/certbot \
  -d trinketandcasa.in \
  -d www.trinketandcasa.in \
  -d api.trinketandcasa.in \
  -d crm.trinketandcasa.in \
  -d upload.trinketandcasa.in \
  --email ommdigitalwebsite@gmail.com \
  --agree-tos --no-eff-email

4) Step 3 After successfuly certificate created Run :  docker compose restart nginx_1
